# QuantForge — Frontend

Готовый фронтенд для существующего FastAPI-проекта `georgelevins7/Trading-Research`.

## Установка

1. Помести папку `frontend` в корень репозитория `Trading-Research` рядом с `app`, `alembic` и `freqtrade-lab`.
2. В одном терминале из корня репозитория запусти бэкенд (активируй Python `.venv`, если требуется):

   ```powershell
   uvicorn app.main:app --reload
   ```

3. Во втором терминале запусти фронтенд:

   ```powershell
   cd frontend
   npm install
   npm run dev
   ```

4. Открой `http://localhost:5173`. Сначала будет экран регистрации / входа. Для работы нужен запущенный FastAPI и PostgreSQL.
5. Проверь сборку после установки пакетов: `npm run build`.

PowerShell может блокировать `npm.ps1`. Тогда используй `npm.cmd install`, `npm.cmd run dev`, `npm.cmd run build`.

## Возможности

- Дизайн: тёмная панель, сайдбар, уведомления, адаптация под телефон.
- Регистрация и JWT авторизация через `/auth/login`, `/auth/register`, `/auth/me`.
- Свечные графики KLineCharts 9.8.12 на реальных публичных данных Binance. Монеты и таймфреймы переключаются.
- Библиотеки стратегий: личные, публичные, встроенные; запуск бэктеста через существующий API.
- Результаты бэктестов, сравнение и график итоговой доходности по **реальным** метрикам, без вымышленных точек сделок.
- AI-конструктор: генерация → ревью → валидация → подтверждение → сохранение или бэктест.
- AI-чат `/ai/chat` с историей 10 последних сообщений в запросе; последние 60 сообщений хранятся в `localStorage` браузера пользователя (чат не сохраняется на сервере).
- Модераторская панель, видимая только при `role === "admin"`.
- DCA симулятор с графиком регулярных покупок и таблицей результатов.

## API и архитектура

В `vite.config.ts` все запросы `/api/*` проксируются на `http://127.0.0.1:8000/*`, поэтому для локальной разработки не нужно менять CORS в FastAPI.

Свечи и котировки загружаются напрямую из публичного API Binance. Если Binance недоступен из сети пользователя, график покажет ошибку и кнопку повтора, а не вымышленные данные.

JWT хранится только в `sessionStorage` текущей вкладки. После истечения токена (1 час в текущем бэкенде) нужно войти заново. Refresh token отсутствует в бэкенде.

## Не реализовано в этой версии

- BUY/SELL маркеры на графике и equity curve: текущий API бэктестов не отдаёт журнал сделок или историю капитала.
- Сохраняемая сервером история диалога: в бэкенде нет таблицы чата.
- Деплой: при настройке сервера нужно настроить Nginx / HTTPS и реверс-прокси `/api` на FastAPI. `vite.config.ts` проксирует API только в dev-режиме.
